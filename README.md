# Sparkle Jewelry Boutique

Create a modern, elegant jewellery e-commerce catalog website for a jewellery brand called "sparkle".

Design:

Minimal, luxurious and feminine aesthetic.

Warm ivory background, soft beige tones, subtle gold accents.

Elegant typography and high-quality jewellery product images.

Fully responsive design.

Features:

Homepage with a hero section, featured collections and product catalog.

Product cards with image, name, price and "Add to Cart" button.

Functional shopping cart with add, remove and quantity controls.

Price filter (min/max price) and category filters (rings, necklaces, bracelets, earrings).

Cart icon with live item count.

Smooth hover effects and subtle animations.

IMPORTANT:
This is a product catalog only. No checkout, payments, online ordering or purchasing functionality. Users can only browse products, filter by price/category and add items to their cart.

Use React, keep the code clean and implement all interactions.
